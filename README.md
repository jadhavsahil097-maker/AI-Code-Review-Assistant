
# AI Code Review Assistant

## Project Description
AI Code Review Assistant is a Python-based application
for reviewing source code and identifying potential
code quality issues.

## Features
- AI-assisted code review
- Code smell analysis
- Performance analysis
- Security analysis
- Review history

## Technologies
- Python
- HTML
- CSS
- SQLite (if used by the project)

## Installation
1. Install Python.
2. Download or clone this repository.
3. Install dependencies:

   pip install -r requirements.txt

## Run
Run the main application file according to the
project configuration.
